# Nothing VPN

Клиент VLESS для Windows (трей, sing-box): режимы **Прокси**, **TUN (весь трафик)** и **TUN (выбранные приложения)**.

## Скачать и установить

Скачайте `NothingVpnSetup.exe` со страницы **[Releases](https://github.com/EXTRBXY/vpn/releases/latest)** и запустите установку.

## Использование

- Запустите **Nothing VPN** из меню Пуск.
- На странице **Профили** добавьте VLESS-ссылку или подписку.
- На **Главной** выберите профиль и режим и нажмите **Подключить**. Для режимов TUN Windows запросит права администратора.
- Для **TUN — выбранные приложения** добавьте программы в **Настройки → Приложения через TUN** (кнопки «Найти приложение» или «Выбрать .exe») и сохраните настройки.
- Проверка связности — **Диагностика → Проверить подключение** (в режиме выбранных приложений не заменяет проверку самих приложений).

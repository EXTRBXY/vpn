# Оформление WPF

Общие размеры и шаблоны находятся в `src/NothingVpn.Desktop.Wpf/Themes/Theme.xaml`.
Светлая и тёмная палитры переключаются `ThemeManager`, цвета в разметке задаются через DynamicResource.
Текст наследует цвет своего контрола: общий стиль TextBlock не должен перекрашивать подписи кнопок.

| Элемент | Правило |
| --- | --- |
| Отступы | Основной шаг 4 px; между подписью и полем 8, между полями 16, между разделами 24 |
| Окна и карточки | PagePadding и CardPadding — 24; карточка скруглена на 16 |
| Поля, кнопки, списки | ControlCornerRadius — 10; высота обычного контрола минимум 44 |
| Компактные панели | Минимальная высота 32, только в таблицах и панели журнала |
| Элементы списков | ItemPadding 12×8, скругление 6, фон выделения одинаков с фокусом и без него |
| Заголовки | Страница 28, диалог 24, раздел 18, SemiBold; основной текст наследует размер 14, пояснения 12 |
| Таблицы | TableFrameStyle со скруглением 10; компактные селекторы и редакторы; без системного светлого выделения |
| Фокус | Рамка поля, ячейки и элемента списка; кнопки сохраняют цвет своего действия |

Используйте общие ресурсы и стили вместо новых локальных размеров. Списки внутри карточек могут иметь
прозрачный фон и нулевую внешнюю рамку; внешнюю форму задаёт карточка. Текстовые поля получают отступы
через TextBox.Padding один раз, без повторного Padding у рамки шаблона.

Панели с несколькими действиями используют WrapPanel, чтобы кнопки переносились при сужении окна.
В редакторах профиля и подписки прокручивается форма, а заголовок и кнопки остаются на месте.
Не фиксируйте высоту формы под один набор текстов: сообщения об ошибках и масштабирование увеличивают содержимое.
Многострочные поля журнала и описания изменений используют VerticalContentAlignment=Stretch и собственную прокрутку.

Проверка: `build/Build.ps1 -Target Test`; визуальные сценарии описаны в
[UI-REGRESSION-CHECKLIST.md](UI-REGRESSION-CHECKLIST.md). `WpfThemeChecks` сохраняет в `artifacts/ui-previews/`
главную, профили, настройки (включая списки), диагностику и все диалоги в двух темах, обычном и компактном размере.
Изображения создаются на изолированных тестовых данных без запуска VPN и без показа окон на рабочем столе.

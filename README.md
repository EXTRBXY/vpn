# Nothing VPN

Клиент VLESS для Windows (трей, sing-box, режим TUN для выбранных приложений).

## Скачать и установить

Скачайте `NothingVpnSetup.exe` со страницы **[Releases](https://github.com/EXTRBXY/vpn/releases/latest)** и запустите установку.

## Использование

- Запустите приложение **Nothing VPN** из меню Пуск.
- Добавьте профиль (VLESS) и включите нужный режим (Proxy/TUN).

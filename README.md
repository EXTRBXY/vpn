# Nothing VPN

Клиент VLESS для Windows (трей, sing-box): режимы **Прокси**, **TUN (весь трафик)** и **TUN (выбранные приложения)**.

## Скачать и установить

Скачайте `NothingVpnSetup.exe` со страницы **[Releases](https://github.com/EXTRBXY/vpn/releases/latest)** и запустите установку.

Установщик запросит права администратора (UAC): приложение ставится для всех пользователей в
`C:\Program Files\NothingVpn` вместе со службой Windows **Nothing VPN**, которая запускает VPN. Сама программа всегда
работает с обычными правами. Установка поверх прежней версии сохраняет профили, подписки и настройки
(`%LOCALAPPDATA%\NothingVpn.Tray`) и убирает старую копию из `%LOCALAPPDATA%\Programs\NothingVpn`. Обновления из
программы тоже подтверждаются в UAC.

## Использование

- Запустите **Nothing VPN** из меню Пуск.
- На странице **Профили** добавьте VLESS-ссылку или подписку.
- На **Главной** выберите профиль и режим и нажмите **Подключить**. Права администратора для TUN не нужны: подключение выполняет служба.
- Для **TUN — выбранные приложения** добавьте программы в **Настройки → Приложения через TUN** (кнопки «Найти приложение» или «Выбрать .exe») и сохраните настройки.
- Проверка связности — **Диагностика → Проверить подключение** (в режиме выбранных приложений не заменяет проверку самих приложений).

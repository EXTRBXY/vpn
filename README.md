# Nothing VPN

Клиент VLESS для Windows (трей, sing-box): режимы **Прокси**, **TUN (весь трафик)** и **TUN (выбранные приложения)**.

## Скачать и установить

Скачайте `NothingVpnSetup.exe` со страницы **[Releases](https://github.com/EXTRBXY/vpn/releases/latest)** и запустите установку.

## Использование

- Запустите **Nothing VPN** из меню Пуск.
- Добавьте профиль (VLESS), выберите режим и нажмите **Старт**.
- Для **TUN (приложения)** укажите полные пути к `.exe` (например `chrome.exe`, `Telegram.exe`).
- Диагностика связности — кнопка **Пинг** (для split-tunnel не заменяет проверку выбранных приложений).
